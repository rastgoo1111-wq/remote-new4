GITHUB SETUP — RASTA Universal Audio IR Remote v11.1.1

1. Extract this ZIP.
2. Upload the CONTENTS of the extracted folder to the root of a GitHub repository.
   The .github/workflows/build.yml file must be at that exact path in the repository.
3. Commit and push the files.
4. Open the repository's Actions tab and select "Android Build".
5. Wait for the workflow to complete.
6. Open the completed run and download the debug APK artifact.
7. For a public release, configure Android signing securely with GitHub Secrets before distributing a release APK.

The workflow runs on pushes to any branch, pull requests, and manual dispatch.
The release APK generated by the current workflow is unsigned.
Do not upload signing keys, passwords, or private credentials to the repository.
